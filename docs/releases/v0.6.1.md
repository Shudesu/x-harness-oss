# v0.6.1 — リリース公開処理の修正

公開日: 2026-10-27（JST）

## 修正

- GitHub Actionsのcheckoutで注釈付きタグがランナー内のcommit参照へ置き換わる場合、originからタグをローカルに取り直して検証します。公開済みリモートタグは変更しません。
- 公開処理だけが失敗した場合は、最新mainのworkflowから既存タグを指定し、再検証して公開できます。
- この修正をタグ付きソースにも含め、画面・API・配布メタデータを`0.6.1`に揃えました。

## 機能と更新

セキュリティ・Grok・支出管理などの機能は[v0.6.0](https://github.com/Shudesu/x-harness-oss/releases/tag/v0.6.0)を引き継ぎます。0.6.0からの追加DBマイグレーションはありません。0.5.x以前から更新する場合は、[既存環境の移行手順](https://github.com/Shudesu/x-harness-oss/blob/v0.6.1/docs/operations/audit-20261026.md)が必要です。

タグから導入する場合はREADMEのv0.6.1手順を使用してください。npmのMCP/CLI/SDKは別管理です。このリリースはnpm公開・本番デプロイ・実DB更新を行いません。

## 検証

186テスト、型チェック、lint、Web/SDK/CLI/MCPビルド、ビルド済みの版番号照合、依存監査、ローカルD1への移行適用、Worker dry-runをCIで検証します。注釈を失わせる再現テストで、タグ復元とリモートタグ不変を確認しています。
