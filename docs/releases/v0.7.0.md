# v0.7.0 — LINE先行キャンペーン

公開日: 2026-10-27（JST）

## 変更

参加者はLINEで本人確認し、「フレーズ-5文字」の個人用合言葉からX投稿へ進みます。X IDの入力はありません。かんたん・標準・厳格、先着・在庫付き抽選、参加賞・個別コードに対応します。照合・条件確認・確定・LINE通知・反応まで実測したファネルを確認できます。

在庫、個別コード、確定結果、outboxは原子的に保存します。コピー、同時刻の投稿、遅れて届く投稿、再送を処理し、通知とユーザーの結果確認が重なっても自動配布を重ねないようにします。新フローはXへ自動投稿やDMを送りません。

## 更新時の注意

- LINE側の対応版（v0.25.0）も必要です。片側だけの更新でキャンペーンを開始しないでください。
- migration 020、連携HMACキー、`GATE_CLAIMS` DO bindingとmigrationが必要です。厳格ティアにはLINE側Turnstile設定も必要です。
- 公開トークンリンクを含む旧配布・自動DM等を停止します。旧X ID自己申告フォームは新参加リンクへ差し替えます。既存の配布履歴・トークンの有効性は保持します。
- 詳細は[導入・移行・復旧ガイド](../operations/line-first-gates.md)を確認してください。DBをバックアップし、実スキーマとmigration履歴を確認してから適用します。

## 検証と制限

コード発行・署名・同時刻・遅延順序・在庫巻き戻し・ページング・予算・旧データ移行の単体テスト、両リポジトリのHTTP契約テスト、実workerdでのPNG/DO/D1スモークを用意しています。

実iOS/Android、実OAuth/Turnstile、実X課金API、実LINE配信、本番移行は未検証です。「必ず4タップ・1分以内」「非参加者のAPI費はゼロ」「完全な本人所有権の証明」は保証しません。検索で観測できた投稿の順序が対象です。

作成ウィザード全体のsaga、告知の自動投稿、当選者OAuth、紹介・ストリーク、Grokの企画生成はMVPの後続です。タグ公開、npm公開、本番デプロイは別操作です。

検証済みのコマンドと件数は[検証記録](../operations/line-first-validation.md)を参照してください。
