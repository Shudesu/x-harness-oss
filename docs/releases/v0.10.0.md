# v0.10.0 — External X observations for reply campaigns

Grok Bot or another owner-connected X reader can supply original post and author data to an explicitly enabled campaign. Harness validates the data shape and applies its existing claim, ranking and inventory rules without using X API reads for that campaign. Partial/stale input holds settlement; it never activates paid fallback.

Enable the mode only from an owner/admin screen for a paused standard reply-only campaign. Follow/like API checks and strict-tier campaigns are not supported in this mode. Existing campaigns keep their current source. Post creation, scheduling, other account analytics and LINE message usage are separate costs. No claim is made that Grok operations are free or that imported observations are independently verified X facts.

Migration023 adds two tables. MCP0.6.0 adds external_gate_sources, external_gate_scan_start, external_gate_page_import; source switching is deliberately not a tool. Cloud exposes the same workflow through three thc_x_gate_* tools and a CSRF-protected owner screen.

See [setup and protocol](../operations/external-observations.md). No real X post, LINE message or customer campaign is sent or activated by release verification.
