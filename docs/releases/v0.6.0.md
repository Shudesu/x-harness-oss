# v0.6.0 — バージョン管理・安全性・Grok連携

公開日: 2026-10-26（JST）

## 主な変更

- 管理画面の`0.0.0`表示を修正。画面・API・`version.json`は同じ版を返し、画面の版番号からこのリリースノートを開けます。
- 予約投稿のUTC/JST混在を修正し、同時実行時の送信重複を防止。明示的な予約は任意の自動収集設定と独立して動きます。
- 公開検索のゲート確認・件数制限・キャッシュ・IP制限、管理者権限の確認、秘密情報の暗号化・移行、短命セッション、OAuth再接続を追加。
- 任意の持ち込みxAIキーでダイジェスト、返信分類、下書き、出典付き調査を利用可能。生成物は自動送信しません。
- リソース単位の推定支出台帳と予算ガード、新規配布のDM既定、署名済みXAA返信の取り込みを追加。既存キャンペーンの配布方法を保持します。
- MCPの投稿取得・メトリクス取得が404になる不足ルートを修正。複数アカウント時は明示選択します。
- LINEキャンペーンの追跡リンク作成をサーバー経由へ統一し、導入ガイドの表示制限とOAuthコールバック案内を修正。
- 公開履歴とCHANGELOGを照合。今後のタグ公開はCI検証後にGitHub Releaseを自動生成します。

## 更新前に必要な作業

**既存環境へコードだけを上書きしないでください。** [移行手順](https://github.com/Shudesu/x-harness-oss/blob/v0.6.0/docs/operations/audit-20261026.md)に従い、DBバックアップ・実スキーマ確認、migration 019、安定した`ENCRYPTION_KEY`、管理画面の`ADMIN_ORIGIN`を準備してください。

- 新規環境は`packages/db/bootstrap`、既存環境はスキーマ確認後の019だけを使用します。
- LIFFの公開ユーザー検索には`gateId`が必要です。CRM検索・返信者一覧は認証必須となります。
- Grokは任意。キーがない場合は保存済みデータ／ルールへフォールバックし、調査だけは最大20件のX API検索を使用します。
- Node.jsは22.13以上を使用してください。ソース内のnpmパッケージ版はMCP 0.4.0 / CLI 0.4.0 / SDK 0.1.1です。Changesetsで別管理し、このタグだけではnpmへ公開しません。導入は[タグからのセットアップ手順](https://github.com/Shudesu/x-harness-oss/tree/v0.6.0#v060--security--cost--optional-grok)を使用してください。
